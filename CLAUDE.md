# GayRetirees.com — Project Rules

These rules are permanent. Follow them on every change, no exceptions.

## Source of truth
- The CSVs in `data/` are the single source of truth. **Never hand-edit `dist/`** —
  it is fully regenerated by `build.py`.
- Every change follows this loop: edit a CSV or `build.py` → rebuild → run tests.

## Factual accuracy
- Factual values (laws, taxes, prices, climate) are never changed without a
  source URL and an as-of date recorded in the CSV.
- Unknown value = leave blank + mark `VERIFY`. Never guess or fabricate a value.

## Claims and rankings
- Rank/numeric claims (e.g. "#1 origin") are allowed **only** on pages whose
  data is third-party cited, with the source and as-of date recorded.
- No page currently qualifies — all copy stays qualitative. Do not add
  superlatives when polishing copy.

## Monetization boundary
- Every paid agent link keeps `rel="sponsored"` and its on-card disclosure.
- Editorial data and rankings are never sold; agent placement is.

## Publishing status
- Pages render a DRAFT stamp until their row is `status=published`.
- Do not flip `status` to `published` without a verified-data pass.

## Human-only content
- Any `dylan_note` field is human-written only. Never generate, draft, or
  placeholder that content. A missing note means the block simply doesn't render.

## Before every commit
- `build.py` must run clean and the full test suite (`tests.py`) must be green.
